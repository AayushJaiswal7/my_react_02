# Basic State App

A minimal React application built with [Vite](https://vitejs.dev/) to demonstrate fundamental React state management concepts. 

This project serves as a learning sandbox or a foundational template for understanding how to manage component state in React using hooks like `useState`.

## 🚀 Features

- **Counter Component:** Demonstrates basic numerical state incrementation and state updates.
- **Like Button Component:** Shows boolean state toggling and interactive UI feedback based on state changes.
- **Fast Development:** Powered by Vite for lightning-fast Hot Module Replacement (HMR).
- **Modern React:** Uses functional components and React Hooks (React 19+).

## 🛠️ Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v16.0 or higher recommended)
- npm (usually comes with Node.js) or yarn / pnpm

## 📦 Installation & Setup

1. **Clone or navigate to the project directory:**
   ```bash
   cd basic-state-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```
   *(or use `yarn install` or `pnpm install` depending on your package manager)*

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to the local URL provided in your terminal (usually `http://localhost:5173/`).

## 📜 Available Scripts

In the project directory, you can run:

- `npm run dev`: Starts the Vite development server with Hot Module Replacement.
- `npm run build`: Bundles the app into static files for production in the `dist` folder.
- `npm run lint`: Runs ESLint to catch and fix code formatting and potential errors.
- `npm run preview`: Bootstraps a local web server to preview the production build generated by `npm run build`.
